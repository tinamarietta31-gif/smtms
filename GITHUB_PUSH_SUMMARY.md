## 🆘 Common Issues & Fixes

| Issue | Fix |
|-------|-----|
| "not a git repository" | Run `git init` |
| "authentication failed" | Use token instead of password, or check SSH key |
| "Please tell me who you are" | Run `git config --global user.email "you@example.com"` |
| "fatal: remote already exists" | Run `git remote remove origin` first |

See TROUBLESHOOTING_GUIDE.md for more.
